# EasyDashboard AI Agent 后续计划

> 状态：后续独立探索，不属于当前产品运行时
> 更新时间：2026-07-30

## 当前产品基线

EasyDashboard 当前以大屏项目为核心。一个项目可以包含多个页面，现有产品闭环已经覆盖：

- 邮箱密码与第三方 OAuth 登录；
- 个人空间、项目搜索、收藏、复制、回收站与恢复；
- 多页面编辑、画布分辨率、草稿保存与乐观并发控制；
- 临时 Undo/Redo、持久恢复点和版本回滚；
- 草稿预览、缩略图、稳定发布地址、版本地址与取消发布；
- 独立、无 Cookie 的公开 Viewer。

模板、团队协作、移动端、2D/3D 扩展和 Agent 都是后续能力，不改变“大屏项目是产品核心”这一边界。

## Agent 的定位

Agent 用于辅助和增强大屏创作，不替代编辑器，也不成为新的产品主流程。预期能力包括：

1. 根据描述生成或补充大屏页面；
2. 修改选中组件、布局、样式和数据配置；
3. 解释变更内容，并让用户继续在编辑器中精调；
4. 在授权范围内执行批量操作；
5. 复用现有保存、恢复点和发布机制。

首页、模板、发布与分享等外围能力可以作为 Agent 的入口或上下文来源，但最终产物仍是可编辑、可预览、可发布的大屏项目。

## 隔离原则

Agent 合同没有验证完成前，实验代码与稳定产品链路保持隔离：

- 不让 Agent 直接写数据库或绕过现有 Hono API；
- 不创建与现有项目文档平行的配置模型，优先操作 EasyEditor 已有文档结构；
- 每次持久变更都经过结构校验、权限校验和版本检查；
- 高影响操作需要明确授权，并在执行前创建可恢复记录；
- Agent 生成的草稿不能自动发布；
- 用户可以选择由平台提供模型能力，或在后续支持的范围内配置自己的 Token；
- 实验失败不得影响编辑器、保存、预览和发布闭环。

## 进入实现前必须确认

- 可调用工具清单、输入输出 Schema 和错误语义；
- 页面、组件、数据源、方法状态等操作与现有 EasyEditor API 的映射；
- 一次性授权、持续授权和危险操作确认边界；
- 并发编辑、版本冲突、撤销与持久恢复点的关系；
- 模型 Token 的加密、脱敏、撤销和使用范围；
- 流式生成期间的中断、重试和部分成功策略；
- 成本、速率限制、审计记录和隐私边界；
- 用真实大屏项目验证的浏览器回归场景。

## 后续里程碑

1. **合同验证**：用最小原型证明工具调用能够安全修改现有项目文档。
2. **隔离实验**：在独立入口中完成单页生成、选中组件修改和恢复验证。
3. **受控接入**：通过功能开关接入个人工作区，不影响默认编辑流程。
4. **体验扩展**：再评估模板、数据建议、2D/3D 组件和多步骤任务。

在合同验证和真实浏览器回归完成前，不把任何里程碑标记为当前实现任务。
